# Docs

These pages are for developers changing Sage. `docs/README.md` is the index.

## Rules

- Link every page from `docs/README.md`.
- Each feature page lists its own bridge commands in a "Bridge commands" section.
- Change the docs in the same PR as the behavior. The pages that most often fall behind are `docs/agent/frontend.md` and `scripts/README.md`.
- Quote UI copy word for word, and bold button names. A copy change in the app is a docs change.
- Name the private sage-evals repo in plain text. Don't link into it.

## Voice

- Short sentences, at most three to a paragraph or bullet.
- Write a flow as steps, one sentence each.
- Use the names the app and the code already use. Add no new jargon.
- Use curly quotes and apostrophes, like the existing pages.

## Skills

- `writing-guidelines` (vercel-labs/agent-skills): reviewing the writing on a page.
